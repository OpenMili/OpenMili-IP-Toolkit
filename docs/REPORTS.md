# 本地报告与终端

推荐的 `simple-ip-check` 两项菜单默认只在终端显示结论，不生成报告目录或页面截图，不启动或下载真实浏览器。终端显示公网出口、ASN/属性、风险、DNS/三网/历史汇总、所有网站普通 HTTP / 浏览器标头两列状态和五维评分。两种方式均使用 curl，模拟标头不执行 JavaScript；详细逐条 DNS、路由和失败证据在显式报告模式查看。通过绿、验证/登录黄、阻断/失败红、未知/跳过灰；支持 `NO_COLOR` 与 `--plain`。高级 CLI 显式启用真实浏览器时保留第三列。

简单 Node 入口加 `--save-report` 或显式 `--output DIR` 才额外保存文件。高级 CLI 保持导出行为，`--terminal` 可改为只在终端展示。导出包含 JSON、单文件 HTML、Markdown、TXT、ANSI；同根目录的 latest.json 用于同出口历史比较。HTML无外部字体/脚本/网络资源，支持深浅主题、窄屏、打印、五维图表、逐跳协议/IP/ASN/RTT、来源证据和评分输入折叠。每张截图<=3MiB时内嵌到HTML，超限/缺失明确显示未嵌入；目录内原文件仍保留。分享脱敏模式不保存/嵌入截图。

报告包含工具/评分/站点规则版本、时区、目标与实际出口、代理来源及能力、各模块状态/错误码/时间、原始证据。JSON Schema在保存前校验，模块聚合依据实际子项结果，执行过但全未知不会显示成功。Token、Cookie、认证头、代理口令及敏感查询参数在所有导出边界统一清除。

高级 CLI 无参数且为交互终端时显示中文菜单，支持1全部、2代理端口、单项检测、R重试、L中英文、0退出。命令行支持静默JSON、纯文本、NO_COLOR、窄屏折行。网站实时进度也使用与最终结果相同的颜色及对照列。英文界面翻译菜单、标准状态及主要流程；第三方/系统原始诊断保留原文供核查。Ctrl+C中断活动任务并展示部分证据；启用文件导出时同时保存。
