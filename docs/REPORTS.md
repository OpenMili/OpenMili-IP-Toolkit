# 本地报告与终端

每次生成 JSON、单文件 HTML、Markdown、TXT、ANSI；同根目录的 latest.json 用于同出口历史比较。HTML无外部字体/脚本/网络资源，支持深浅主题、窄屏、打印、五维图表、逐跳协议/IP/ASN/RTT、来源证据和评分输入折叠。每张截图<=3MiB时内嵌到HTML，超限/缺失明确显示未嵌入；目录内原文件仍保留。分享脱敏模式不保存/嵌入截图。

报告包含工具/评分/站点规则版本、时区、目标与实际出口、代理来源及能力、各模块状态/错误码/时间、原始证据。JSON Schema在保存前校验，模块聚合依据实际子项结果，执行过但全未知不会显示成功。Token、Cookie、认证头、代理口令及敏感查询参数在所有导出边界统一清除。

无参数且为交互终端时显示中文菜单，支持1全部、2代理端口、单项检测、R重试、L中英文、0退出。命令行支持静默JSON、纯文本、NO_COLOR、窄屏折行，进度行含已耗时和网站计数。英文界面翻译菜单、标准状态及主要流程；第三方/系统原始诊断保留原文供核查。Ctrl+C中断活动任务并尽可能保存部分证据。
