## 公网实测（不是 fixture）

运行 `node scripts/verify-live-p1.cjs`：

- 8.8.8.8：RIPE 与 Cymru 均返回 AS15169、8.8.8.0/24；IANA 选择的 `https://rdap.arin.net/registry/ip/8.8.8.8` 返回匹配范围。
- 2606:4700:4700::1111：RIPE 与 Cymru 均返回 AS13335、2606:4700:4700::/48；官方 ARIN RDAP 返回匹配范围。此查询不强制使用 IPv6 传输 API 请求。
- 1.1.1.1 的 UDP/TCP 实际查询 example.org A，分别 DNS_NOERROR，191.62ms / 357.86ms。
- DoT 实测 DNS_TLS_FAILED，未标成功；直连 DoH 为 DOH_FAILED。
- 两个样本均无已授权的 IP/前缀类型库证据，类型正确为 UNKNOWN，不靠 Google/Cloudflare 名称推断。

另显式运行 `--git-proxy`：RIPE/Cymru 成功，官方 RDAP 在该代理路径上超时，保留 UNKNOWN；DoH 经该代理成功（DNS_NOERROR、328ms）。程序没有悄悄切换到直连。直连和代理是两次明确不同的测量。

未配置商用 Key，不宣称商业属性、AbuseIPDB 或所有实际网络条件全部通过。DoT 在本地 localhost 测试证书显式 CA 下完成真实可信 TLS+DNS 查询；错误主机名证书被拒绝。测试 CA 仅供该调用，不安装信任、不用于实际公网请求。
