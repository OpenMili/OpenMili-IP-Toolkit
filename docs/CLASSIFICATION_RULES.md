# 类型证据融合 v1

类型支持 UNKNOWN、MOBILE、RESIDENTIAL、SUSPECTED_RESIDENTIAL、BUSINESS、DATACENTER、OTHER；信誉风险另存，机房不会因类型本身扣分。

仅 IP/前缀级使用类型可作为主要分类票。ASN 名称/品牌、ASN 内置映射、RIR 登记组织不能证明住宅或机房；它们现在只给出低置信度的机房/运营商/移动倾向，等待第二组独立类型证据确认。没有任何类型或 ASN 所有者线索时才显示 UNKNOWN。

每条类型证据记录来源、粒度、抓取时间、来源更新时间、可靠性、权重和依赖组。相同来源组同一结论只取最大权重，不重复投票；商业来源上游依赖没有核实时合为同组。至少两组新鲜 IP/前缀证据一致才输出具体类型；冲突保留支持和反对证据。住宅标签与托管/代理矛盾只提示“疑似”，不指控网络所有者。

权重 = 新鲜度 × 粒度 × 来源可靠性 × 100。IP 粒度 0.8、前缀 1；ASN 所有者/内置映射只作为 30/100 的低置信度提示，不进入正式评分票；来源更新时间未知/较旧时新鲜度再折半；过期缓存权重 0。置信度只是本工具的证据指数，不是统计意义上的真实概率。

风险标签、外部举报和类型分开。false / 零举报只是已查库没有对应记录，不是永久干净证明。BGP 起源差异单列 asn_conflict，不强行把 MOAS 当成类型冲突或滥用。
