Portable OpenMili-IP-Toolkit with an included Node runtime and production dependencies. Download the archive matching your OS/architecture and verify SHA256SUMS. The browser worker is optional (`--browser`); system curl is required. Linux portable archives require glibc; Alpine/musl uses the tested source/Node entry instead.

Measures the actual local/proxy or authorized SSH Agent egress. Includes multi-source identity, independent risk, DNS protocols, sourced operator routes, 38 versioned website rules, five-dimensional scoring and local JSON/HTML/Markdown/TXT/ANSI reports. UNKNOWN is retained when evidence is insufficient. Scores do not guarantee registration, playback or a clean IP.

See README, docs/INSTALLATION.md, docs/AGENT.md and docs/DEVELOPMENT_PLAN.md for commands, actual validation evidence and platform limits. The separate route endpoint directory retains its GPL-3.0-only terms; Node/npm and dependencies retain their licenses.
